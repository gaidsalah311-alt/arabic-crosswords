# تكامل إعلانات Google Mobile Ads

المشروع الحالي تطبيق ويب/PWA يعمل دون إنترنت، لذلك لا يمكن تضمين Google Mobile Ads SDK الأصلي داخل ملفات React وحدها. ملف `client/src/lib/ads.ts` يوفّر جسرًا اختياريًا باسم `window.AdMobBridge` يمكن لغلاف Android أو iOS استدعاؤه عند تحويل التطبيق إلى نسخة Native.

## عقد الجسر

يجب أن يعرّف الغلاف الأصلي الدالتين التاليتين:

```ts
window.AdMobBridge = {
  showInterstitial: async () => {
    // اعرض الإعلان فقط إذا كان محمّلًا، ثم resolve حتى لا تتوقف اللعبة.
  },
  showRewarded: async () => {
    // أعد true فقط بعد استدعاء حدث المكافأة فعليًا.
    // أعد false عند الإلغاء أو الفشل أو عدم توفر الإعلان.
  },
};
```

يتم استدعاء الإعلان البيني بعد إكمال المرحلة رقم 3 و6 و9 و12… فقط. لا يتم استدعاؤه عند تشغيل التطبيق أو أثناء اللعب أو بعد كل مرحلة. وإذا لم يكن الإعلان جاهزًا تستمر اللعبة مباشرة.

## إعلانات الاختبار أثناء التطوير

عند استخدام Google Mobile Ads في الغلاف الأصلي، استخدم معرّفات Google الاختبارية الرسمية فقط:

- Android Interstitial: `ca-app-pub-3940256099942544/1033173712`
- Android Rewarded: `ca-app-pub-3940256099942544/5224354917`
- iOS Interstitial: `ca-app-pub-3940256099942544/4411468910`
- iOS Rewarded: `ca-app-pub-3940256099942544/1712485313`

لا تستخدم معرّفات الإنتاج أثناء الاختبار. ولا يحتاج مستودع الويب إلى مفتاح API أو قاعدة بيانات أو تسجيل دخول.

## قواعد الأمان

الإعلانات اختيارية بالكامل. أي استثناء من SDK أو الجسر يتم تجاهله داخل `ads.ts`، ولا يؤدي إلى Crash أو يمنع الانتقال داخل اللعبة. لا تُمنح مكافأة التلميح إلا إذا أعاد `showRewarded()` القيمة `true` بعد اكتمال حدث المكافأة الأصلي.
